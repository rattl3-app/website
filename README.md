# Rattle - Career Transition App Landing Page

The #1 App for Layoffs and Life Readjustment

## 🚀 Quick Deploy

### Vercel (Recommended)
1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project" → Import your GitHub repo
4. Click "Deploy" - that's it!

### GitHub Pages
1. Go to repo Settings → Pages
2. Set Source to "main" branch
3. Your site will be live at `https://yourusername.github.io/rattle-website`

## 🔗 Custom Domain Setup

To connect your domain (e.g., rattl3.com):

### For Vercel:
1. Go to Project Settings → Domains
2. Add your domain
3. Update DNS records as instructed

### For GitHub Pages:
1. Add a `CNAME` file with your domain
2. Update DNS to point to GitHub Pages
